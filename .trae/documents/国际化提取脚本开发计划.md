## 国际化提取脚本开发计划

### 项目分析
- **目标**：提取 src/pages 目录下所有 TSX 文件中的中文文本
- **当前状态**：项目使用直接中文字符串，未使用 i18n 函数
- **输出格式**：数组格式保存到 zh_CN.json

### 脚本功能
1. **遍历目录**：递归遍历 src/pages 目录下的所有 .tsx 文件
2. **中文提取**：使用正则表达式提取文件中的中文文本
3. **去重处理**：确保提取的中文文本不重复
4. **文件输出**：将提取的中文文本以数组格式写入 zh_CN.json

### 技术实现
- **使用 Python**：跨平台支持
- **正则表达式**：提取中文字符
- **文件操作**：读写 JSON 文件
- **递归遍历**：处理目录结构

### 脚本步骤
1. **解析命令行参数**：支持指定目录路径
2. **遍历文件**：递归查找所有 .tsx 文件
3. **提取中文**：使用正则表达式匹配中文
4. **合并去重**：收集所有唯一的中文文本
5. **写入文件**：生成 zh_CN.json 文件
6. **显示统计**：输出提取结果统计信息

### 正则表达式设计
```python
# 匹配中文字符（包括常见标点）
chinese_pattern = r'[\u4e00-\u9fa5]+[\u4e00-\u9fa5\s\p{P}]*[\u4e00-\u9fa5]+'
```

